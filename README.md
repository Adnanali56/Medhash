# MEDHASH: Medical Record Hashing System

A menu-driven C++ application that compares hashing and collision-resolution techniques for indexing synthetic medical records: linear probing, quadratic probing, double hashing, separate chaining, bucket hashing, alternate bucket hashing with overflow, and rehashing.

**Course:** CSC-3422 / CSC-6021 Data Structures II

All patient data in this project is synthetic. No real patient information is used.

## Build and Run (Ubuntu)

    g++ -std=c++17 -Wall -Iinclude src/*.cpp -o medhash
    ./medhash
